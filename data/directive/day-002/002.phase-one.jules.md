### I. ARCHITECTURAL REQUIREMENTS & IMPLEMENTATIONS

#### 1. Deterministic Foley Unit (`packages/500.viewport/10.foley.unit/buz/foley.buzz.ts`)

Remove `debugger` and implement:
- `murmurHash3(key: string, seed = 0): number` and `mulberry32(seed: number): () => number`.
- `PARALLAX_FOLEY_CATALOG`: Maps the 9 *Parallax Dinner* Foley categories (`rain_squall`, `diesel_idle`, `door_hiss`, `booth_creak`, `menu_drop`, `coffee_pour`, `wipe_tear`, `lens_click`, `semi_pass`) to trigger keywords, default frame durations (`integer > 0`), and 3 sample WAV paths each (`assets/foley/<cue>_v1.wav`, `_v2.wav`, `_v3.wav`).
- `resolveFoleyPlacements(sceneId: string, cues: Array<{ text: string; fromFrame: number; durationInFrames?: number }>): FoleyPlacementSpec[]`:
  - Matches action text against `PARALLAX_FOLEY_CATALOG`.
  - Computes `seed = murmurHash3("${sceneId}:${category}:${fromFrame}")` and selects a variant via `mulberry32(seed)`.
  - Applies `:retry1` anti-clustering salt if the same category was placed within `< 120` frames and selected the identical variant path.
- `unrollFoleySequencesJsx(placements: FoleyPlacementSpec[]): string`:
  - Validates integer `fromFrame` and `durationInFrames` (`ERR_FLOAT_FOLEY_FRAME` on floats/negatives) and returns unrolled `<Sequence from={...} durationInFrames={...}><Audio src={staticFile("...")} volume={...} /></Sequence>` blocks.

#### 2. Deterministic Ambience Unit (`packages/500.viewport/02.ambience.unit/buz/ambience.buzz.ts`)

Remove `debugger` and implement:
- `mergeSpeechWindows(windows: SpeechWindowSpec[], maxGapFrames = 18): SpeechWindowSpec[]`: Sorts and merges speech windows where `next.fromFrame - (curr.fromFrame + curr.durationInFrames) <= maxGapFrames`.
- `computeAmbientDuckingCurve(totalFrames: number, windows: SpeechWindowSpec[], floorDb = -14.0, attackFrames = 6, releaseFrames = 12)`: Computes per-frame linear gain (`10^(db/20)`, `0.1995` at `-14.0 dB`) with 6-frame quadratic attack and 12-frame quadratic release.
- `unrollAmbientTrackJsx(ambientWavPath: string, windows: SpeechWindowSpec[], baseVolume = 0.35, duckedVolume = 0.20): string`: Generates the static Track 3 `<Audio src={staticFile("...")} volume={(f) => ...} loop />` JSX block using merged speech windows.
